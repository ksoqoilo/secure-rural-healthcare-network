# Secure Rural Healthcare Network

## Overview 
This project designs and simulates a secure network architecture for a fictional rural healthcare centre in the Solomon Islands using Cisco Packet Tracer.
It explores how network security principles can support secure and reliable digital healthcare services in rural environments

Ongoing
